# 系统架构

## 1. 模块划分

| 模块 | 目录 | 技术方向 | 职责 |
| --- | --- | --- | --- |
| 前端 | `frontend` | Vue3 + Vite | 用户端页面、管理员页面、接口调用和数据展示 |
| 后端 | `backend` | Spring Boot | 业务接口、事件管理、数据库访问、模型服务调用 |
| 模型服务 | `model-service` | Python + FastAPI + YOLOv8 | 图片识别，返回违法类型、置信度和检测框 |
| 数据库 | `database` | MySQL | 表结构、初始化数据、演示数据 |
| 文档 | `docs` | Markdown | 产品说明、接口契约、协作规范、部署说明 |

## 2. 调用关系

```text
用户/管理员浏览器
  -> frontend
  -> backend
  -> database

设备端
  -> backend
  -> model-service
  -> backend
  -> database

管理员统计页面
  -> frontend
  -> backend
  -> database
```

## 3. 核心数据流

### 3.1 违法事件生成

```text
设备上传图片
  -> 后端接收设备编号、抓拍时间、图片
  -> 后端调用模型服务 /detect
  -> 模型服务返回识别结果
  -> 后端生成违法事件
  -> 数据库存储事件记录
```

### 3.2 违法事件查询

```text
前端页面发起查询
  -> 后端按用户、状态、设备或时间筛选
  -> 数据库返回事件数据
  -> 后端统一包装响应
  -> 前端展示列表或详情
```

### 3.3 审核状态更新

```text
管理员提交审核结果
  -> 后端校验事件是否存在
  -> 后端更新事件状态和备注
  -> 数据库保存审核结果
  -> 前端刷新事件状态
```

## 4. 模块边界

### 4.1 前端边界

前端负责：

- 页面展示和交互。
- 调用 `docs/api.md` 中约定的接口。
- 处理加载、空状态、错误提示。
- 不直接访问数据库或模型服务。

### 4.2 后端边界

后端负责：

- 对外提供统一业务接口。
- 校验请求参数和业务状态。
- 读写数据库。
- 调用模型服务并转换识别结果。
- 统一响应格式和错误处理。

### 4.3 模型服务边界

模型服务负责：

- 接收图片文件。
- 执行识别或模拟识别。
- 返回识别标签、置信度和检测框。
- 不直接写数据库，不处理管理员审核逻辑。

### 4.4 数据库边界

数据库负责：

- 保存用户、管理员、设备、违法事件等结构化数据。
- 提供初始化演示数据。
- 不承载业务判断逻辑。

## 5. 接口契约原则

- 前后端以 `docs/api.md` 为唯一接口约定。
- 修改接口路径、方法、字段、状态枚举时，必须同步更新 `docs/api.md`。
- 后端调用模型服务时，也应把模型服务接口视为契约，不应在未确认的情况下随意改字段。
