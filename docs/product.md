# 产品说明

## 1. 项目定位

非机动车智能违法监管与服务平台面向非机动车违法治理场景，提供违法事件采集、智能识别、后台审核、用户查询和统计分析能力。当前项目定位为原型系统，用于完成课程、大创或答辩演示中的核心闭环。

## 2. 用户角色

| 角色 | 主要目标 | 典型操作 |
| --- | --- | --- |
| 普通用户 | 查询个人违法记录和事件详情 | 查看违规列表、查看违规图片和状态 |
| 管理员 | 管理违法事件、设备和统计数据 | 查看事件列表、审核事件、查看设备状态、查看统计分析 |
| 设备端 | 上报抓拍图片和设备信息 | 上传图片、上报抓拍时间和设备编号 |
| 模型服务 | 识别图片中的违法行为 | 接收图片、返回识别标签、置信度和检测框 |

## 3. 核心业务流程

### 3.1 设备上报与识别

1. 设备端抓拍图片。
2. 设备调用后端上报接口，提交设备编号、抓拍时间和图片。
3. 后端保存上报信息，并调用模型服务进行识别。
4. 模型服务返回违法类型、置信度和检测框。
5. 后端生成违法事件，初始状态进入待审核或待处理流程。

### 3.2 管理员审核

1. 管理员查看违法事件列表。
2. 管理员进入事件详情，查看图片、设备、时间和识别结果。
3. 管理员更新事件状态，例如确认违法、驳回或进入复核。
4. 系统保存审核结果，并用于用户端查询和统计分析。

### 3.3 用户查询

1. 用户进入个人违法记录页面。
2. 系统按用户 ID 查询违法列表。
3. 用户查看单条违法详情，包括违法类型、时间、状态和图片。

### 3.4 统计分析

1. 管理员选择时间范围或筛选条件。
2. 系统统计违法总数、当日数量、类型分布和趋势数据。
3. 前端展示统计结果，用于演示监管效果。

## 4. 当前版本范围

当前版本优先完成演示闭环：

- 用户端违法列表和详情查询。
- 管理员端违法列表、详情、状态审核。
- 设备上报事件。
- 模型服务识别接口联通。
- 设备列表查询。
- 违规统计查询。
- MySQL 表结构和初始化演示数据。

## 5. 暂不纳入当前版本

以下内容可作为后续扩展，不应影响当前版本交付：

- 完整账号注册、短信验证、权限系统。
- 真实摄像头硬件接入和持续视频流处理。
- 复杂申诉流程、罚款支付、执法文书生成。
- 高并发部署、生产级监控、容灾备份。
- 多模型训练、模型评估平台和自动标注平台。

## 6. 验收标准

当前版本完成时，应至少满足：

- 前端能展示核心页面并调用约定接口。
- 后端接口返回结构符合 `docs/api.md`。
- 数据库能通过初始化脚本生成演示数据。
- 模型服务 `/detect` 能接收图片并返回识别结果。
- 管理员能完成一次事件审核状态更新。
- 项目能按 `docs/deployment.md` 在本地启动或明确标注未完成模块。
